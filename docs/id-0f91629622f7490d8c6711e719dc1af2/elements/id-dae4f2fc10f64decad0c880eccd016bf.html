Diversifikation ()

Die Diversifikation gilt für Unternehmen, deren Geschäftsbereiche nur wenige gemeinsame Kunden, Lieferanten oder Geschäftsabläufe haben. Geschäftsbereiche in diversifizierten Unternehmen bieten unterschiedliche Produkte und Dienstleistungen für unterschiedliche Kunden an, so dass die zentrale Leitung nur eine begrenzte Kontrolle über diese Geschäftsbereiche ausübt.
